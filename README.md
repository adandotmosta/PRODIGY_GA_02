# Text-to-Image Generation with Stable Diffusion

Generating images from text prompts with **Stable Diffusion**. Task 2 of my Generative AI internship at Prodigy InfoTech.

## What it does

- Loads a pretrained Stable Diffusion model with **KerasCV**, using XLA compilation for faster generation
- Generates 256×256 images from detailed text prompts, for example *"a man dancing with an umbrella under the sea, high quality, highly detailed"*
- Displays the generated images

## Tech stack

Python, TensorFlow, Keras, KerasCV, Matplotlib
